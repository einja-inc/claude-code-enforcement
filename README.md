# グローバルCLAUDE.md 自動セットアップガイド

このディレクトリには、すべてのプロジェクトで共通して使用するグローバルルールと、新規プロジェクト用の自動セットアップツールが含まれています。

## 📁 ファイル構成

```
C:\Users\musta\.claude\
├── CLAUDE.md              # グローバルルール（すべてのプロジェクトで参照）
├── init-project.py        # 新規プロジェクト用セットアップスクリプト（Python）
├── init-project.bat       # 新規プロジェクト用セットアップスクリプト（Windows）
└── README.md              # このファイル
```

## 🚀 使い方

### 1. 新規プロジェクトのセットアップ

新しいプロジェクトフォルダで作業を開始する際、以下のコマンドを実行してください：

#### 方法1: プロジェクトフォルダから実行
```bash
# プロジェクトフォルダに移動
cd C:\Users\musta\Desktop\新しいプロジェクト

# セットアップスクリプトを実行
C:\Users\musta\.claude\init-project.bat
```

#### 方法2: パスを指定して実行
```bash
# どこからでも実行可能
C:\Users\musta\.claude\init-project.bat "C:\Users\musta\Desktop\新しいプロジェクト"
```

#### 方法3: Pythonスクリプトを直接実行
```bash
# プロジェクトフォルダに移動
cd C:\Users\musta\Desktop\新しいプロジェクト

# Pythonスクリプトを実行
python C:\Users\musta\.claude\init-project.py
```

### 2. 実行結果

スクリプトを実行すると、以下が自動的に行われます：

1. **既存のCLAUDE.mdのバックアップ**（存在する場合）
   - `CLAUDE.md.backup_YYYYMMDD_HHMMSS` という名前で保存

2. **新しいCLAUDE.mdの作成**
   - グローバルルールへの参照を含む
   - プロジェクト固有のルールセクション（テンプレート）を含む

### 3. セットアップ後の作業

1. **プロジェクトのCLAUDE.mdを編集**
   ```
   C:\Users\musta\Desktop\新しいプロジェクト\CLAUDE.md
   ```

   以下のセクションをプロジェクトに合わせて編集：
   - プロジェクト情報
   - 技術スタック
   - 命名規則
   - プロジェクト固有の禁止事項
   - プロジェクト固有のワークフロー

2. **グローバルルールを確認**
   ```
   C:\Users\musta\.claude\CLAUDE.md
   ```

3. **開発を開始**

## 📚 グローバルルールの内容

グローバルCLAUDE.md ([C:\Users\musta\.claude\CLAUDE.md](C:\Users\musta\.claude\CLAUDE.md)) には、以下のルールが含まれています：

### 必須ツール・ルール
- ✅ **Byterover MCP**: 知識の保存・取得（retrieve/store）
- ✅ **Codex常時協力**: 全ファイル修正でCodex analystと協力
- ✅ **Gemini妥当性検証**: ビジネスロジックの検証
- ✅ **Seraphina自動相談**: 複雑度スコア50以上で必須
- ✅ **TodoWrite**: 8-10項目必須
- ✅ **並列実行強制**: Task()を並列で実行

### 禁止事項
- ❌ **忖度修正の絶対禁止**: 指示された内容のみ実行
- ❌ **要件の勝手な変更・判断の絶対禁止**: 推測による実装禁止

### 8層強制システム
1. Pre-commit Git Hook
2. MCP監査エージェント
3. 並列実行強制Wrapper
4. Seraphina自動相談システム
5. Session監視（リアルタイム）
6. Post-task検証Hook
7. 自動修正提案システム
8. リアルタイム通知システム

## 🔧 グローバルルールの更新

グローバルルールを更新する場合：

1. **グローバルCLAUDE.mdを編集**
   ```
   C:\Users\musta\.claude\CLAUDE.md
   ```

2. **すべてのプロジェクトに自動反映**
   - 各プロジェクトのCLAUDE.mdはグローバル版を参照しているため、自動的に反映されます
   - プロジェクトごとにファイルを更新する必要はありません

## 💡 よくある質問

### Q1: 既存のプロジェクトにもセットアップできますか？
**A**: はい。既存のCLAUDE.mdは自動的にバックアップされます。

### Q2: グローバルルールを変更した場合、既存のプロジェクトにも反映されますか？
**A**: はい。各プロジェクトのCLAUDE.mdはグローバル版を参照しているため、自動的に反映されます。

### Q3: プロジェクト固有のルールはどこに書きますか？
**A**: 各プロジェクトの `CLAUDE.md` の「プロジェクト固有のルール」セクションに追記してください。

### Q4: グローバルルールとプロジェクト固有ルールが矛盾する場合は？
**A**: グローバルルールが常に優先されます。プロジェクト固有ルールは、グローバルルールと矛盾しないようにしてください。

### Q5: 自動セットアップスクリプトが動かない場合は？
**A**: 以下を確認してください：
- Pythonがインストールされているか
- グローバルCLAUDE.md ([C:\Users\musta\.claude\CLAUDE.md](C:\Users\musta\.claude\CLAUDE.md)) が存在するか
- プロジェクトフォルダへの書き込み権限があるか
