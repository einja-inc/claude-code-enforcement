## Common Issues

### Issue 1: "Git repository not found"

**Cause:** Running installer outside a git repository

**Solution:**
```bash
cd C:\Users\musta\Desktop\PJ\いいんじゃ\フォーム分析
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py install
```

### Issue 2: "Permission denied"

**Cause:** File permissions issue (rare on Windows)

**Solution:**
```bash
# Reinstall with elevated permissions
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py install
```

### Issue 3: "compliance_scores.jsonl not found"

**Cause:** Layer 5 Session Monitor not running

**Solution:**
1. Start Session Monitor:
   ```bash
   py C:\Users\musta\.claude\enforcement\daemon\service_manager.py start
   ```

2. Or create dummy score file for testing:
   ```bash
   echo {"score": 100, "timestamp": "2025-11-15T17:30:00", "violation_count": 0} > C:\Users\musta\.claude\enforcement\logs\compliance_scores.jsonl
   ```

### Issue 4: Hook not running

**Cause:** Hook file not in correct location or not executable

**Solution:**
```bash
# Verify installation
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py verify

# Reinstall
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py install
```

### Issue 5: Colors not showing

**Cause:** colorama not installed

**Solution:**
```bash
pip install colorama
```

## Maintenance

### Update hook

To update the hook to a newer version:

```bash
# Uninstall old version
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py uninstall

# Install new version
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py install
```

### Backup existing hook

Before installation, the installer automatically backs up existing hooks to:
```
.git/hooks/pre-commit.backup
```

### Reset to defaults

To restore original git behavior:

```bash
py C:\Users\musta\.claude\enforcement\git_hooks\install_hooks.py uninstall
```
